# SoftSite web app

Next.js front end for SoftSite. See the repository root `README.md`, `CLAUDE.md`, and `docs/` for the full picture.

```bash
npm install        # also copies MapLibre's worker into public/vendor/
npm run dev        # http://localhost:3000
```

The data in `public/data/` is generated by the Python pipeline (`uv run pipeline all` from the repo root).
