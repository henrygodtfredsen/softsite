# data/manual/

Inputs that come from Bodie's browser rather than from an automated download, because those sites block scripts. Step-by-step instructions are in [`docs/MANUAL_STEPS.md`](../../docs/MANUAL_STEPS.md).

- `source_docs/`: zoning code chapters, specific plans, General Plan, and Housing Element PDFs. **Not committed**; they're cited by section and page in `config/zoning_rules.csv`.
- `projects_listing/`: saved City Projects Listing pages. **The HTML is not committed** (it contains staff contact details); only the extracted project fields are.
